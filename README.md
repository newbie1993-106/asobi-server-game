# 遊び鯖運営ゲーム

`index.html` を開くだけで遊べる、保存なし・1プレイ完結のブラウザゲームです。外部ライブラリやビルド作業は必要ありません。

## 公開方法

このフォルダをそのまま静的サイトとして公開できます。

- GitHub Pages: リポジトリへ3ファイルを置き、Pages の公開元をそのリポジトリに設定する。
- Cloudflare Pages: 新しい静的サイトの作成時にこのフォルダをアップロードする。ビルド設定は不要。

公開先のURLを知っている人は、ブラウザだけでプレイできます。

## 実装済みのルール

- 106 / 1993 / 第三の各ルートと独立したクリア条件
- 自然減少、D連続時の追加減少、30未満の同時トラブル
- DAY10開始時の???解放判定（∞は除外）と夏休み明けイベント
- TRUE ROUTE と専用のGAME OVER演出
